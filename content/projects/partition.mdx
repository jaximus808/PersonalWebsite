Partition is a full stack mobile app that I'm currently working on that will be able to provide personal budgeting through the 50/30/20 budget method. 

The app uses the PlaidAPI to get financial information and then the begetting app uses this to create detailed reports of your expense usage. The app uses mongoDB as the backend and Google Oauth as a way for users to login in a convenient and familiar method. The mobile app is made with flutter and other encompassing packages.

The app currently has user authentication set up with Google's OAuth and is able to get financial information and display them on the mobile frontend. The app also allows categorizing of transaction which is then used to budget in which area's a user is spending in.

Some future features I want to add is to make an easier method to categorize transactions. I also need to do some backend clean up. Currently though I have learned a lot about full stack systems and OAuth, which for some reason I never really understood until now.
