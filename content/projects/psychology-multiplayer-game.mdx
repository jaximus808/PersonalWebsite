This game was created for an AP Psychology project in 11th grade to help students memorize terms that my group gave a presentation about. The project involves 4 teams racing to see who can get the most food until the time runs out. To collect the food the players must run to the middle of the map, answer a psychology question correctly, and then run home and return the food.

The project uses nodejs, a javascript framework, and socket.io, a module used to help with real-time communication, as the server. The game is only designed for one game at a time, however, in the future, this may be updated. Nodejs hosts the html/css/js clients for the players to use on the web. The client itself uses vanilla HTML/css and javascript, the graphics itself mainly uses a library called p5. 

In the future, this project may be updated for more use other than psychology and could allow people to create their own rooms with their own questions.
